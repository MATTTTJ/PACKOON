## 1. 한 줄 결론

**지역마다 구역 다섯 개를 짧은 순환길로 잇고, 한 번 넘어온 지역 경계만 왕복하게 하는 안을 추천한다.**

[확정 기획](../../design/gdd/neoguri-concept.md)과 CSV를 기준으로 기존 진행을 유지한다. 아래 새 구역명·연결·추가 교환·시간·치수는 모두 **제안(예)**이다. ‘속도보다 접근 능력’은 기획서 §11에는 제안으로 남아 있지만, 이번 설계의 원칙으로 적용했다.

## 2. 선택지

**A. 작은 순환길 — 추천**

기존 교환 순서대로 전진하되, 높은 길이나 지하 곁길이 앞서 지나온 장소로 돌아온다. 처음에는 막힌 길을 보고, 물건이나 통행 허락을 얻은 뒤 직접 연다.  
좋은 점은 NPC와 채집지를 다시 찾는 과정에서도 새 길을 발견한다는 것. 넓은 미로를 헤매는 맛은 약하다. **만들기 크기: 중간.**  
§14의 가방 성장을 정하기 전에도 배치할 수 있다. 밤 동물은 기존 NPC 네 명 안에서 구성하고, 전투 탈은 필드 통행 조건에 쓰지 않는다.

**B. 거점과 세 갈래**

지역 입구의 거점에서 채집길·교환길·보스길이 뻗는다. 각 길 끝에서 거점으로 돌아와 준비하고 다음 갈래로 향한다.  
목적지를 구별하기 쉽지만, 기존 교환 연쇄를 그대로 넣으면 같은 거점을 자주 왕복하게 된다. 갈래마다 별도 풍경도 필요하다. **만들기 크기: 큼.**  
§14의 기록 구성에는 갈래별 할 일을 찾는 방식을, 가방 성장에는 거점으로 돌아올 동기를 함께 반영하는 편이 좋다.

## 3. 추천안 상세

현재 웹은 네 지역 모두 가로 길이 2,400이며 다음 지역으로만 넘어간다. 아래 **x는 현재 코드의 좌표**이고 새 맵의 고정 치수가 아니다. 도식의 `─`는 양방향, `→`는 조건을 채운 뒤 열리는 귀환길이다.

시간은 첫 방문의 이동·대화·채집·가공·미니게임·전투를 합친 **목표 예산**이다. 실측값은 아니며, 실패 반복이나 채집물 재생 대기로 시간을 채우지 않는다.

### 단풍골

현재 도담 x300 → 날쌘 820 → 무쇠 1110 → 두꺼비 할멈 1430, 덩굴문 1660, 엉킨 칡 2180, 당산나무 2214 순서다.

```text
[마을 입구 8분]─[물레방아 8분]─[대장간 10분]─[약초비탈 8분]─[당산나무 12분]
                   ↑__________________________│ 낫으로 여는 귀환길
```

**합계 46분(예).** 도담은 입구, 날쌘은 물레방아, 무쇠는 대장간, 할멈은 약초비탈에 둔다. 도토리는 낮은 참나무길과 나무 발판 위에 나누고, 칡뿌리는 비탈 흙층에 둔다. 보스 전에 버섯 두 종류를 만나 달래기도 준비하게 한다.

낫을 얻으면 기존 덩굴문과 물레방아로 돌아오는 비탈길이 열린다. 당산나무 위 전망 발판은 보스 뒤에 열어 해머루 획득 순서를 유지한다. **물레방아 언덕에서 당산나무 꼭대기와 감긴 칡을 먼저 보여 준다.**

**재방문 연결:** 돌너머의 돌쇠와 마른 억새 1을 바꿔 **매듭줄 1(예)**을 얻는다. 물레방아 옆 말뚝에 묶으면 아래 수로로 내려가 숨은 버섯 자리와 물레방아 밑 풍경을 발견한다. 매듭줄은 소모하지 않는다.

### 돌너머

현재 꾸벅이 x320 → 날쌘 820 → 돌쇠 할배 1150 → 뿔이 1560, 통행문 1590, 골렘 1990, 서리다래 2236이다.

```text
[장승 어귀 8분]─[억새·메밀밭 9분]─[석수마당 10분]─[장승고개 8분]─[성황당·절벽 13분]
                                      ↑________________________│ 보스 뒤 지하 귀환길
```

**합계 48분(예).** 꾸벅이는 어귀, 날쌘은 밭 가장자리, 돌쇠는 석수마당, 뿔이는 장승고개에 둔다. 밭은 낮게 펼치고 겨우살이는 나무 발판 위에, 석수마당 아래에는 지하 통로를 배치한다. 절벽은 마지막 구역에서 높이를 크게 드러낸다.

맷돌을 깨우고 메밀가루를 건네는 통행 조건을 유지한다. 지하 귀환길은 골렘 뒤에 열어 이 조건을 우회하지 못하게 한다. **밭 둔덕에서 장승 너머 성황당 돌무더기가 움직이는 모습과 뒤쪽 절벽을 보여 준다.** 석이버섯은 기존대로 골렘을 달랜 뒤 뿔이에게 위치를 들어야 찾는다.

**재방문 연결:** 큰 장터의 보부상 신표를 뿔이에게 보여 주면 **옛 석수 통로(예)**를 안내받는다. 지하 통로 옆 이끼 바위 방이 열리며, 기존 석이버섯 자리와는 별개로 둔다.

### 큰 장터

현재 모락 x360 → 엿방울 640 → 날쌘 960 → 숙소 마루 1070 → 부엉 영감 1190, 창고 1500, 솔방울 1700~2300이다. 마루는 시설이므로 NPC는 네 명이다.

```text
[떡집 10분]─[엿골목 10분]─[보부상 숙소 9분]─[창고 8분]─[뒷산 솔숲 13분]
                              ↑________________________│ 위쪽 귀환길
```

**합계 50분(예).** 떡집과 엿골목은 낮은 생활 공간, 숙소는 마루와 처마의 두 층, 솔숲은 낮은 채집길과 높은 귀환길로 나눈다. 필수 솔방울 다섯은 낮은 길에서 얻고 여분 셋은 통나무 위에 둔다.

떡집 굴뚝의 김은 여러 구역에서 방향을 알려 주고, 숙소 현판과 등불은 귀환 기준이 된다. 신표를 받고 밤에 창고를 지키는 조건은 유지한다. **지키기를 맡은 뒤 숙소 처마에서 창고 틈의 푸른 불빛을 먼저 보게 한다.**

밤 동물은 **부엉 영감이 낮에는 숙소 안에서 자고 밤에 마루로 나오며, 엿방울은 밤에 차분해지는 안(예)**을 추천한다. 새 NPC를 추가하지 않는다.

**재방문 연결:** 영산에서 얻은 설피로 솔숲의 깊은 눈길을 지나 **숙소 지붕 뒤 전망자리(예)**에 닿는다. 추가 솔방울과 장터 야경을 보상으로 둔다.

### 북쪽 영산

현재 날쌘 x260 → 살금이 1480 → 아빠 1740 → 산군 1920, 깊은 눈길 790, 얼음 비탈 1600, 보스 2120, 신목 2236이다. 보스는 이름 변경이 확정됐으므로 여기서는 **영산 보스**로 부른다.

```text
[산막 8분]─[눈길·마가목비탈 10분]─[산지기길 10분]─[호숫가 9분]─[신목섬 13분]
    ↑________________________________________________________│ 봄에 열리는 귀환길
```

**합계 50분(예), 마지막 교환과 엔딩 포함.** 산막 주변의 덩굴과 처마 밑 짚은 설피 없이 얻는다. 마가목은 설피로 지난 뒤, 살금이를 만나기 전에 충분히 채집하게 한다.

설피 → 살금이와 교환해 지름길 확인 → 아빠 → 산군 → 보스 순서를 유지한다. **마가목 비탈의 전망턱에서 호수·신목·호수를 감싼 똬리 그림자를 함께 보여 준다.** 호숫가와 섬 사이에는 처음부터 돌징검을 보여 둬 봄에 얼음이 녹아도 왕복할 수 있게 한다.

호감으로 열리는 샛길은 짧은 전망 공간에만 쓴다. 아빠의 장부와 엄마의 진실은 주 진행에서 받는다. 영산 뒤에는 다음 지역이 없으므로 외부 능력으로 돌아오는 연결은 만들지 않는다. 대신 봄에 눈이 걷힌 길로 산막까지 돌아보는 **선택 산책 3~5분(예)**을 둔다. 약연으로 약을 만들면 기존대로 엔딩으로 간다.

### 채집과 지역 왕복

필수량은 낮고 찾기 쉬운 길에서 확보하고, 높은 곳과 숨은 곳에는 여분을 둔다. 미니게임을 잘했을 때 받는 덤은 필수량에 넣지 않는다.

- 단풍골: 도토리 최소 6, 칡뿌리 1. 달래기를 준비할 버섯 두 종류도 보스 전에 배치.
- 돌너머: 메밀 6을 확보해 통행용 가루를 만들고 다음 지역에 남길 몫을 둔다. 억새는 꾸벅이에게 줄 몫과 매듭줄 교환 몫을 확보.
- 큰 장터: 솔방울 5를 확보. 엿방울의 쌀 8 지급은 유지하고 숨은 길 교환에는 쓰지 않는다.
- 영산: 덩굴 2·짚 1은 눈길 앞, 마가목 3은 얼음 비탈 앞에서 확보.

일반 채집 자리는 다른 지역에서 돌아왔을 때 **자리마다 게임 전체에서 한 번만 보충(예)**한다. 메밀은 남은 이삭, 솔방울은 새로 떨어진 것으로 표현한다. 낮밤 전환만으로는 보충하지 않으며 귀한 열매·보스 보상·사연물은 다시 주지 않는다.

**1~3지역에서 약을 발송하고 다음 지역에 처음 들어가면, 넘어온 경계가 양방향으로 열린다(예).** 지역별 문·보스·보상 수령 상태를 보존하고 날쌘은 현재 방문 지역에만 등장한다. 웹에는 없는 추가 구조다. 재방문은 각 3~6분을 더하는 선택 활동이며 본편 완료에 필요하지 않다.

도깨비불씨는 오래된 시나리오의 파괴 전용 조건을 따르지 않고, **확정 기획대로 달래도 받는다.** 위 숨은 길에는 불씨를 소모시키지 않는다.

### 네 지역 공통 레벨 문법

- **발판:** 기본 점프 최고 높이를 H, 같은 높이에서 최대 이동 거리를 D로 잡는다. 필수 발판은 높이 차 0.5~0.65H, 간격 0.5~0.6D, 너비는 캐릭터 폭의 2.5배 이상(예). 높은 발판일수록 간격을 좁힌다.
- **시야:** 뛰기 전에 다음 착지점을 보여 준다. 위로 오르는 길에서는 카메라가 먼저 위쪽을 비추고, 낙하 지점 아래에도 안전한 바닥을 보여 준다.
- **막힌 길:** 낫에는 질긴 줄기, 매듭줄에는 묶을 말뚝, 설피에는 깊이 빠진 발자국, NPC 허락에는 빗장이나 금줄을 대응시킨다. 같은 조건에는 같은 표시를 쓴다.
- **숨은 길:** 바람에 흔들리는 풀과 바닥 틈처럼 서로 다른 흔적 두 개를 둔다. 배경 벽을 무작정 치게 하지 않는다.
- **실수:** 발판에서 떨어지면 가까운 안전 지점으로 돌아오며 물건 손실이나 진행 초기화는 없다(예). 전투 탈은 전투에서만 쓴다.

## 4. 대장에게 물을 것

아래 예시 배치와 공통 문법을 기본안으로 두고 네 가지를 고르면 된다.

1. **맵 형태:** **A 작은 순환길(추천)** / B 거점과 세 갈래
2. **지역 왕복:** **A 넘어온 경계만 왕복하고 매듭줄·재방문 연결 세 곳 추가(추천)** / B 일방향 유지, 매듭줄과 재방문 연결 보류
3. **큰 장터 밤 구성:** **A 밤에 나오는 부엉 영감 + 차분해지는 엿방울(추천)** / B 밤에 나오는 부엉 영감 + 속내를 털어놓는 날쌘
4. **채집물 보충:** **A 재방문 때 일반 채집 자리마다 전체 여정 중 한 번 보충(추천)** / B 보충 없이 첫 배치량만 사용
