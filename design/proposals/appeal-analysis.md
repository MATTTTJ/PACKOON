# 매력 분석과 볼륨 설계 — 언더테일에서 배울 것, 우리만의 것 (Claude 분석 · 개발자 결정용)

결론부터: **언더테일의 분량은 "화면마다 무언가가 말을 건다"는 밀도에서 나온다.** 우리 게임에는 그 밀도가 없고, 대신 언더테일에 없는 것(물물교환이 곧 진행, 가족의 가보, 이름을 잃는 병, 계절이 흐르는 여정)이 있다. 그래서 언더테일의 **밀도 문법**을 빌려 우리 재료를 채운다. 전투 위주 분량(무작위 조우)은 빌리지 않는다.

## 1. 언더테일이 매력적인 이유

1. **전투가 곧 대화다.** 평범한 몬스터마다 고유한 "행동"(칭찬·쓰다듬기·같이 춤추기)이 있고, 그걸 알아내면 싸우지 않고 끝난다. 조우 하나하나가 1분짜리 캐릭터다. 그리고 "죽이지 않는다"는 선택에 무게가 있다.
2. **적고 깊은 주연.** 파피루스·샌즈·언다인·알피스·토리엘. 각자 원하는 것과 모순이 뚜렷하고, 선택해서 함께 보내는 시간(데이트·놀기)이 있다. 웃기다가 진심이 되는 순간이 매력의 핵심이다.
3. **세계가 기억한다.** 무엇을 했는지에 따라 대사가 바뀌고, 다시 해도 세계가 알아챈다. 행동에 결과가 남는 감각.
4. **레벨 디자인의 리듬.** 지역마다 거점 마을(스노우딘) 하나 + 그 앞뒤로 퍼즐 복도. 화면 하나에 한 가지 생각만: 안전하게 가르치고 → 시험하고 → 비튼다(퍼즐이 농담으로 끝나기도 한다). 걷기 → 농담 → 퍼즐 → 조우 → 이야기의 짧은 순환이 쉼 없이 돈다. 큰 볼거리(빛나는 폭포, 다리 위 대치)가 지역마다 하나씩.
5. **조사하면 다 대답한다.** 표지판·물건·배경 몬스터까지 짧은 농담이 붙어 있다. 싸게 만들 수 있는데 밀도는 가장 크게 올린다.
6. **인물마다 음악 동기.** 같은 선율이 장면마다 변주된다.
7. **작은 규모, 높은 밀도.** 맵 자체는 작다. 대신 빈 화면이 없다.

## 2. 우리 게임만의 매력

1. **돈이 없다. 물건을 건네는 것이 곧 마음을 건네는 것.** 교환이 진행이고, 선물이 달래기다. 언더테일의 "행동"을 우리는 **물건과 행동**으로 한다.
2. **가보에 가족의 손이 있다.** 절구·맷돌·시루·약연을 지역마다 깨우고, 쓰면서 가족의 손버릇을 배운다 (크래프팅 설계).
3. **이름과 기억을 잃는 병, 이름을 내놓는 결말.** 주인공은 끝까지 이름이 없고, 동물들이 붙여 주는 별명과 기록만 쌓인다.
4. **아빠의 길을 따라간다.** 젊은 아빠가 남긴 수첩과 도장, 지난가을 아빠의 흔적이 지역마다 겹쳐 있다. 두 시간대의 같은 길.
5. **한국의 계절과 민속.** 늦가을 → 첫서리 → 설 장날 → 늦겨울·첫봄. 당산나무·성황당·장승·도깨비·이무기.
6. **수묵화 부위 공략 전투.** 부숴서 재료를 얻을지, 달래서 마음을 풀지.

**지금 약한 곳**: 밀도(빈 화면이 많다), 인물이 기능에 머묾, 지역이 한 화면짜리 일자길, 길 위에서 만나는 게 없음, 가공이 진행용뿐, 경치가 없음.

## 3. 빌릴 것 / 빌리지 않을 것

| 언더테일 | 우리 게임에서 |
|---|---|
| 몬스터 조우 + 행동 | **길손**: 1~2분짜리 만남, 물건이나 행동으로 마음을 푼다. 무작위 조우는 하지 않는다 (탐험 리듬이 깨진다) |
| 거점 마을 + 퍼즐 복도 | **거점 구역 + 갈래 구역**: 지역마다 NPC 가 모인 거점 하나, 갈래 두셋 |
| 화면 하나에 한 생각 | **구역 하나에 새것 하나**: 새 길·새 동사·새 볼거리 중 하나 |
| 조사 농담 | **조사 거리**: 아이의 호기심과 지역 계절. 농담보다 작은 발견 |
| 세계가 기억 | **별명과 기록**: 동물들이 아이가 한 일로 부르고, 다시 오면 그 일을 말한다 |
| 큰 볼거리 | **경치 자리** 두 곳: 멈춰 서서 보는 곳 |
| 인물 음악 동기 | 지역·인물 짧은 선율 (웹은 합성음 수준, Godot 에서 본격) |
| 죽이지 않는 선택의 무게 | 이미 있다: 부술지 달랠지. 달래면 인물 사연이 조금 더 열린다 |
| 메타(저장 기억) | 빌리지 않는다. 이야기 톤과 맞지 않는다 |

## 4. 레벨 디자인 원칙 (지역 작업에 그대로 적용)

1. **거점과 갈래.** 지역마다 거점 구역 하나(NPC 대부분, 쉬는 곳, 집으로 보내는 까치)와 갈래 구역 두셋. 보스는 가장 먼 갈래 끝.
2. **구역 하나에 새것 하나.** 구역에 들어설 때 "여기는 무엇이 새롭나"가 분명해야 한다: 새 풍경 / 새 동사(덩굴 걷기, 설피, 낮밤) / 새 인물.
3. **구역 안의 리듬.** 들어서는 풍경 → 길손이나 조사 거리 → 채집 무리나 작은 지형 도전 → 인물 사연 한 장면 → 경치나 다음 출구. 빈 화면이 3초 넘게 이어지지 않게.
4. **접근 능력으로 여는 길.** 낫·설피·신표·낮밤·호감. 먼저 막힌 길을 **보여 주고**, 나중에 열리게 한다. 열린 뒤 그 길 끝에는 반드시 보상(도장·경치·길손·숨은 재료).
5. **돌아오면 달라진다.** 접근 능력을 얻고 거점으로 돌아오면 조사 글·NPC 대사·길손 하나가 바뀐다.
6. **높낮이 세 층.** 구역마다 땅 / 중간 발판 / 높은 곳. 비밀은 높은 곳이나 눈에 덜 띄는 끝에.
7. **가르치고 → 시험하고 → 비튼다.** 지역의 새 동사는 안전한 곳에서 처음 보여 주고, 다음 구역에서 조금 어렵게, 보스에서 비틀어 쓴다.
8. **밀도 목표 (구역당)**: 인물 또는 길손 1, 조사 거리 3, 비밀 1(도장·숨은 재료·숨은 가공법 단서), 채집 무리 1, 높낮이 지형 1.
9. **지역의 정체성**: 색 두 가지, 소리 하나, 날씨 입자 하나, 경치 둘. 이 다섯이 지역마다 겹치지 않게.

## 5. 볼륨 설계

**웹 완성판 목표 (오늘 밤)**: 지역당 25~35분, 전체 약 2시간 (처음 하는 사람).

| 재료 | 지역당 수 | 분 |
|---|---|---|
| 필수 진행(교환·미니게임·보스) | 기존 | 6~8 |
| 인물 사연 장면 | 9~12 | 4~7 |
| 구역 탐험·이동·돌아오기 | 구역 4~5 | 5~8 |
| 길손 | 3~4 | 4~6 |
| 크래프팅(손맛·발견·좋아하는 맛) | 가공 4~6회 | 3~5 |
| 아빠 도장 | 3 | 2~3 |
| 조사 거리 | 12~15 | 2~3 |
| 경치 | 2 | 1~2 |
| **합계** | | **27~42분** |

**Godot 정식판 목표**: 지역당 40~60분. 같은 문법을 그대로 늘린다.
- 길손 3~4 → 6~8 (지역 사이를 오가는 길손 줄거리 포함)
- 구역 4~5 → 6~7, 구역마다 작은 지형 퍼즐 1
- 인물 사연 3장면 → 4~5장면 + 인물끼리 얽힌 사건 지역당 1
- 가공법 16 → 24, 좋아하는 맛 표 확대
- 인물·지역 음악 동기, 계절 전환 연출
- 웹에서 재미가 검증된 재료만 늘린다. 재미없던 건 늘리지 않는다.

## 6. 하지 않는 것

- 같은 행동을 시간만 늘리려고 반복시키기 (가져와·전해 줘·같은 채집 두 번).
- 무작위 조우, 경험치·레벨.
- 화면만 넓고 아무것도 없는 구역.
- 엔딩 반전(엄마의 거래 값, 이름의 값)을 영산 전에 말하기.
