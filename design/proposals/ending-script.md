# PA-37 · 엔딩 연출 대본 (제안)

> **Claude 검토 (2026-10-29)** — 아래 대본은 Codex 초안이다. 받아들이기 전에 걸리는 점:
> - **좋은 점**: 아빠의 침묵을 끝까지 지키고, 실패·판정이 없으며, 이름 입력의 한글 조합·빈칸 처리가 꼼꼼하다.
> - **절정이 약하다.** 가장 큰 보상인 "엄마가 새 이름을 부르는 순간"의 엄마 대사가 "왔구나 / 이름을… / 새로 지어 줄게"로 기능만 한다. 이 게임 내내 아이를 "그 녀석 아들"로 부르던 세계가 처음으로 이름을 부르는 순간이니, 엄마 대사는 대장이 직접 쓰는 게 맞다.
> - **아빠의 길을 답습한다(확정)는 주제가 닫히지 않는다.** 5장면에서 아빠 수첩의 "여기다."를 비추기만 한다. 제안: 마지막에 아이가 **아빠의 발바닥 도장 옆에 자기 도장을 찍는다** (A4 발바닥 도장 확정과 이어지고, 대사 없이 된다).
> - **3·4장면이 겹친다.** 약연이 깨어나는 장면과 열매를 가는 장면이 따로 있어 같은 도구를 두 번 보여 준다. 하나로 합쳐 140초를 줄이자.
> - **확인 선택을 두 번 묻는 것(질문 2의 A)은 반대.** 이미 "…조금만 생각해 볼게요"로 물러날 수 있는데 한 번 더 확인하면 결단의 순간이 흐려진다. B를 추천한다.
> - 엄마가 "반딧불로 둔갑해 방을 밝힌다"는 오프닝과 짝을 이루는 좋은 장면이다. 유지.

이름을 내놓은 뒤 아빠와 약을 만들고, 함께 집으로 돌아오는 여덟 장면을 제안한다. **연출·대사·시간·입력 규칙은 모두 제안**이다. 주인공의 이름을 엔딩 전까지 밝히지 않는 것, 이름 교환, 엄마의 회복과 새 이름 직접 입력, 아빠의 침묵은 확정 설정을 따른다.

근거: [영산 시나리오](../narrative/yeongsan-scenario.md), [기획서 §4·7](../gdd/neoguri-concept.md), [아빠 사연 제안](crafts-and-dad-past.md). 현재 [영산 엔딩 코드](../../prototypes/web/js/regions/yeongsan/story.js)의 `giveName`·`goHome`·`endExtra`, [끝 문단](../../prototypes/web/js/regions/yeongsan/region.js)의 `cover.end`, [끝 화면 코드](../../prototypes/web/js/engine/game.js)의 `showEnd`와 [화면 구조](../../prototypes/web/index.html)를 참고했다. 이 문서는 코드 변경을 포함하지 않는다.

길이는 보통 속도로 읽었을 때의 기준이며, 입력·대기 시간은 별도다. 합계 약 **140초 + 이름 입력 시간**. 대사는 진행 버튼을 누를 때까지 남긴다. 아빠의 행동은 자막 대사로 읽히지 않게 한다. 배경은 신목·보따리·초가·한지로 잡고, 머리 위 나뭇잎·큰 배와 술병·삿갓은 쓰지 않는다.

## 1쪽 · 마지막 교환과 약연

### 1. 산군과의 마지막 교환 · 30초

- **화면:** 도트. 봄빛 호숫가 신목 아래, 산군과 부자가 한 화면에 선다. 카메라는 장부와 열매가 놓인 자리로 천천히 다가간다. 장부의 기존 글 “제 둔갑과 말을 드립니다. 아이의 숨을 주세요.”와 “말 하나 더함.”을 차례로 비춘다.
- **소리·음악:** 녹은 물 흐르는 소리. 대금 한 음을 길게 두고 장단은 멎는다.
- **대사:** 산군: “어미의 둔갑과 말. 두 가지다.” / “네 아비가 말을 보탰다. 하나가 모자라.” / 주인공: “제 이름을 드릴게요.” / 산군: “누구도 그 이름을 기억하지 못한다.” / “네 아비의 말도 돌아오지 않는다.”
- **조작:** 기존 선택지 “제 이름을 드릴게요” / “…조금만 생각해 볼게요”. 후자는 필드로 돌아가며 손실이 없다. 전자는 산군의 마지막 두 마디 뒤 “이름을 내놓는다” / “아직은…”으로 뜻을 확인한다. 교환 실패나 다른 결말은 두지 않는다.

### 2. 이름을 내놓는 순간 · 12초

- **화면:** 도트. 주인공 얼굴을 가까이 비춘다. 엄마가 이름을 부르려다 멈추던 입 모양을 짧게 겹친 뒤 지운다. 옛 이름은 글자·음성 어느 쪽으로도 내보내지 않는다. 주인공이 빈손을 내밀면 산군이 고개를 끄덕인다. 주인공은 자기 가슴에 손을 댄다.
- **소리·음악:** 대금이 끊긴 뒤 2초간 정적. 곧 물소리만 돌아온다.
- **대사:** 산군: “셈은 맞았다.” 주인공은 말없이 아빠를 돌아본다.
- **조작:** 없음. 이름을 입력하거나 맞히게 하지 않는다.

### 3. 손을 포개 약연이 깨어남 · 18초

- **화면:** 도트. 보따리에서 꺼낸 약연과 두 손을 고정 화면으로 보여 준다. 아빠가 아이 손 위에 손을 포개 바퀴를 함께 굴린다. ‘되돌림’ 글자에 옅은 빛이 돈다. 곁의 낡은 수첩에는 아빠의 발바닥 도장이 보인다.
- **소리·음악:** 돌 구르는 낮은 마찰음에 가야금 한 가락이 붙는다. 성공 효과음은 짧게 한 번.
- **대사:** 주인공: “같이 해요, 아빠.” 아빠는 손에 힘을 보태고 끄덕인다.
- **조작:** “함께 굴리기”를 한 번 누르면 끝까지 이어진다. 연타·타이밍 판정·실패는 없다.

## 2쪽 · 약을 들고 집으로

### 4. 되돌림 약 · 10초

- **화면:** 도트. 깨어난 약연의 홈을 가까이 비춘다. 전설의 열매가 갈리고 연분홍 약이 작은 약병에 담긴다. 아빠가 병을 아이 손에 쥐여 준다.
- **소리·음악:** 열매 으깨지는 소리, 병 내려놓는 소리. 앞 장면의 선율을 조용히 잇는다.
- **대사:** 주인공: “엄마한테 가요.” 아빠는 남쪽을 가리킨다.
- **조작:** 기존 가공 흐름처럼 약연에 전설의 열매를 한 번 넣는다. 손실 없이 약이 완성되며 귀향으로 이어진다.

### 5. 아빠의 길에서 집으로 · 18초

- **화면:** 도트. 젊은 아빠가 남긴 수첩의 신목 그림, “여기다.”, 발바닥 도장을 가까이 비춘다. 글씨는 원래 있던 그대로다. 아빠가 수첩을 덮고 아이와 나란히 걷는다. 고정된 횡화면 세 컷으로 영산 산길 → 지나온 마을길 → 집 대문을 잇는다. 처음 따라오던 아빠의 발자국 옆에 이제 아이의 발자국이 남는다.
- **소리·음악:** 두 사람의 발소리. 여행 선율을 느리게 변주하고 집 앞에서 처마 풍경 소리로 넘긴다.
- **대사:** 없음. 아빠는 대문 앞에서 아이의 보따리를 받쳐 준다.
- **조작:** 없음. 단서를 얼마나 찾았든 같은 장면이다. 젊은 아빠의 귀향 약속 안이 채택되면 앞서 본 약속을 떠올릴 수 있게 하되, 여기서 설명 대사를 더하지 않는다.

### 6. 엄마가 되찾는 둔갑과 말 · 25초

- **화면:** 도트. 방 안을 고정된 옆모습으로 잡는다. 아이가 엄마에게 약을 먹이고 아빠가 등을 받친다. 해가 지는 짧은 전환 뒤 엄마가 반딧불로 둔갑해 방을 밝힌다. 오프닝과 같은 구도를 쓴다. 다시 너구리 모습으로 돌아온 엄마가 아이를 부르려다 멈추고, 얼굴을 쓰다듬는다. 아빠는 말없이 웃는다.
- **소리·음악:** 약을 삼키는 소리와 밤벌레 소리. 엄마의 첫마디에 음악을 낮춰 목소리를 들려준다.
- **대사:** 엄마: “왔구나.” / “이름을….” / “엄마가 새로 지어 줄게.” 주인공: “네.”
- **조작:** 없음. 엄마가 이름을 잊던 병은 거래의 값이었고, 이제 옛 이름은 모두에게 사라졌다는 차이를 이 멈춤으로 보여 준다. 아빠에게 말이 돌아오는 연출은 없다.

## 3쪽 · 새 이름과 마지막 장면

### 7. 엄마가 새 이름을 지어 주는 화면 · 15초 + 입력 시간

- **화면:** 도트 방을 그대로 두고 엄마 손 옆에 작은 한지 입력창을 띄운다. 카메라는 멈춘다. 제목 **“엄마가 지어 주는 새 이름”**, 안내 **“엄마가 불러 줄 이름을 적어 주세요. 1~6글자.”**, 빈칸 안내 **“새 이름”**, 버튼 **“이 이름으로 불러 주세요”**. 입력값은 엄마가 짓는 이름으로 다룬다.
- **소리·음악:** 밤벌레 소리와 짧은 가야금 선율을 낮게 반복한다. 입력을 재촉하는 소리는 없다.
- **대사:** 확정 전 엄마: “어떤 이름이 좋을까.” 확정 뒤 엄마: “{새 이름+아/야}.” 예: “봄별아.” / “봄이야.”
- **조작·예외:** 직접 입력 후 버튼 또는 Enter로 확정한다. 한글 조합 중 Enter는 확정으로 받지 않는다. 앞뒤 공백을 뺀 뒤 보이는 글자 단위로 센다. 빈칸·공백만 있으면 “새 이름을 적어 주세요.”, 6글자를 넘으면 “여섯 글자까지 적을 수 있어요.”를 칸 아래에 표시하고 입력과 초점을 유지한다. 긴 이름을 임의로 자르거나 기본 이름으로 채우지 않는다. 한글 받침에 맞춰 ‘아/야’를 붙이고, 한글 외 문자로 끝나면 “우리 {새 이름}.”으로 부른다.

현재 코드는 6자리 입력 제한과 잘라내기를 쓰며, 빈칸에는 초점만 돌려준다. 위 안내·예외는 이를 바꾸자는 제안이다. 이름은 외부로 보내지 않고 현재 끝 화면에서만 쓴다. 확정 직후 새로고침하면 다시 입력하는 안으로 두며, 영구 저장은 이번 제안에 넣지 않는다.

### 8. 마지막 장면 · 12초

- **화면:** 도트. 입력창이 걷히면 아이가 엄마 쪽으로 몸을 기댄다. 아빠가 두 사람 어깨를 감싼다. 카메라가 조금 물러나 마루에 놓인 보따리와 덮인 수첩까지 담는다. 마지막 글은 **“너구리 보부상 · 끝”**. 가족이 있는 정지 화면을 남긴다.
- **소리·음악:** 주인공의 대답 뒤 가야금이 한 번 맺고, 처마 풍경과 밤벌레 소리만 남는다.
- **대사:** 주인공: “네, 엄마.” 아빠는 말없이 눈을 접어 웃는다.
- **조작:** 장면이 끝나면 기존 “아빠의 수첩 보기” / “처음부터”를 표시한다. 단서 수·쓰러진 횟수는 가족 장면 위에 띄우지 않고 수첩에서 확인하게 하는 안이다.

### 대장에게 물을 것

1. **엔딩 그림은?** A. 전 장면 도트, 손·수첩만 확대(추천) / B. 이름을 내놓는 순간과 약연 장면만 수묵 삽화로 전환.
2. **마지막 교환 확인은?** A. 대가를 들은 뒤 한 번 더 선택(추천) / B. 기존 선택 한 번으로 교환, 대가는 선택 전에 모두 설명.
3. **새 이름을 부른 뒤 마무리는?** A. 위 12초 가족 장면과 정지 화면(추천) / B. 짧게 서로 바라본 뒤 바로 끝 화면.
