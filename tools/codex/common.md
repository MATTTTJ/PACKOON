## 공통 규칙 (꼭 지킬 것)
- 이 폴더는 2D 횡스크롤 게임 "너구리 보부상"의 웹 프로토타입 레포다. 먼저 CLAUDE.md 와 prototypes/web/README.md 를 읽어라.
- 빌드 없이 브라우저로 여는 순수 JS다. 새 라이브러리나 빌드 도구를 넣지 마라.
- 아래 "고칠 파일"에 적힌 파일만 고친다. 다른 파일이 꼭 필요하면 고치지 말고 마지막 보고에 이유를 적어라.
- git commit, push, 브랜치 변경은 하지 마라. 작업 폴더에 고친 상태로만 두면 된다.
- 한글은 UTF-8 글자 그대로 쓴다. \uXXXX 이스케이프 금지.
- CSV(design/data/*.csv)는 UTF-8 BOM 을 유지한다. id 칸은 바꾸지 않는다. CSV 를 고쳤다면 레포 맨 위에서 `node prototypes/web/tools/build-data.js` 를 돌려 prototypes/web/js/data/tables.js 를 다시 만든다 (tables.js 를 손으로 고치지 마라).
- 일본 너구리(타누키) 표식(머리 위 나뭇잎, 큰 배와 술병, 삿갓)은 쓰지 않는다.
- 끝나면 고친 JS 파일마다 `node --check <파일>` 으로 문법을 확인한다.
- 글쓰기 다듬기 같은 스킬은 쓰지 마라. 필요 없다.
- 마지막 답변(한국어)에는 무엇을 어떻게 바꿨는지, 확인한 방법, 남은 걱정만 짧게 적어라.
