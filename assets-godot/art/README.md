# 아트 에셋 (Godot 4용 원본)

필드 아트는 손으로 칠한 회화풍이다 (2026-11-04 사용자 결정, 시안의 노을 단풍 숲길 배경이 기준). 전투 수묵화풍은 그대로다.
기획서 §2 확정 칸("필드는 픽셀 도트, 차선책 동화풍")과 다르므로 대장에게 알린다.

## 원칙

- **모든 오브젝트는 디퓨즈(빛 없는 고유색) + 노말맵 한 쌍이다.** 하이라이트·그늘·림 라이트·발밑 그림자·안개 원근을 그림에 굽지 않는다. 밝기와 방향은 게임 조명(Godot 4 2D 조명)이 준다.
- 예외: 하늘(`bg_sky_*`)은 칠한 그림 그대로 쓰고 노말맵이 없다.
- 빛줄기, 반딧불, 빛 알갱이, 굴뚝 연기, 낙엽 흩날림은 그림이 아니라 게임의 조명·파티클로 만든다. 파티클용 작은 텍스처만 에셋으로 둔다.
- 물체는 잘리지 않은 온전한 형태로 만든다. 화면 맨 앞의 어두운 액자 오브젝트(늘어진 가지, 앞 단풍나무)만 잘려도 된다.
- 일본 표식 금지(머리 위 나뭇잎, 술병, 삿갓 석상, 도리이, 지그재그 흰 종이 줄). 금줄은 왼새끼에 고추·숯·솔가지·곧은 한지.

## 해상도 기준

화면 목표는 4K(3840×2160)이고, 카메라는 웹 게임보다 조금 멀리 본다 (화면 높이 약 280 게임 단위, 웹 게임은 225).
그래서 **게임 1단위에 약 7.7px** 이 필요하다. 에셋 원본의 픽셀 높이는 `게임 높이 × 7.7` 이상이어야 한다 (`stage1/assets.csv`의 필요높이 칸).

| 묶음 | 만드는 법 |
|---|---|
| 큰 소품·인물 | 그림 한 장에 하나씩, 도구 최대 크기 (약 157만 화소: 세로 1024×1536, 정사각 1254, 가로 1448×1086) |
| 작은 소품·식생 | 정사각 시트에 2×2 (한 칸 600px 이상) |
| 배경 겹 | 긴 띠(2172×724)를 오른쪽으로 이어 그려 늘리고, 끝을 처음과 이어 반복되게 한다. 늘려서 키우지 않는다 |

## 제작 순서 (에셋 하나)

1. **디퓨즈**: Codex 그림 생성. 배경은 크로마키 마젠타. 이미 마음에 든 빛 칠한 시안이 있으면 그것을 입력으로 빛만 걷어 낸다.
2. **노말맵**: 디퓨즈를 입력으로 그림 편집 (OpenGL 규약, 초록이 위). 디퓨즈와 윤곽 겹침을 자동으로 재서 0.9 아래면 다시 뽑는다.
3. **정리**: 마젠타 빼기, 번짐 지우기, 여백 자르기. 원본은 PNG로 `stage1/<id>/diffuse.png`, `normal.png` 에 둔다.
4. **웹용**: 줄인 WebP를 `prototypes/web/art/` 로 내보내 맵 확인 페이지에서 조명과 함께 본다.

## 할일 단계

제작(Codex 그림 생성) → 조립(웹 맵 확인 페이지에 배치, Claude) → 검수(사용자가 걸어 다니며 웹 게임 맵과 구조 비교).
목록은 `stage1/assets.csv` 가 원본이다. 진행 칸은 `할 일 → 디퓨즈 → 노말 → 조립 → 검수 통과` 로 바꾼다.
