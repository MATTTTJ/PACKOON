# 너구리 보부상 (PACKOON)

엄마의 병을 고칠 전설의 열매를 찾아, 소식이 끊긴 아빠의 길을 따라 여행하는 너구리 보부상의 2D 횡스크롤 탐험·수집 게임. 돈 없이 물물교환으로만 성장하고, 보스급 재료를 얻을 때만 수묵화풍 부위 공략 전투가 열린다.

## 플레이

브라우저에서 바로: **https://mattttj.github.io/PACKOON/** (갈참골 체험판)

PC는 키보드(←→ 이동, Space 점프, J 휘두르기, E 말걸기, I 보따리, B 책), 휴대폰은 화면 버튼으로 조작한다.

## 진행 방식

지금은 웹 버전으로 모든 지역의 콘텐츠와 게임 루프를 정하는 단계다. 정해지면 Godot 4로 새로 만든다.
